## Что мы читаем из CSV

```python
with open("orders.csv", encoding="utf-8-sig", newline="") as f:
    rows = list(csv.DictReader(f))
```

`open` открывает файл, а `with` автоматически закрывает его после чтения. `utf-8-sig` позволяет читать кириллицу и возможную служебную метку в начале файла. `newline=""` оставляет обработку переносов строк модулю `csv`.

`csv.DictReader` превращает каждую строку в словарь. Например, `row["category"]` — категория одного заказа. `list` сохраняет все строки в список `rows`, чтобы можно было проходить по ним несколько раз. Всего в файле **5 463 строки**.

| Поле | Что хранит |
| --- | --- |
| `order_id` | Номер заказа |
| `order_date` | Дата и время |
| `customer_id` | Код клиента |
| `city` | Город |
| `category` | Категория товара |
| `amount` | Сумма заказа |
| `delivery_days` | Срок доставки; в этих задачах не используется |
| `status` | `оплачен` или `отменён` |

Значения из CSV — строки, даже если выглядят как числа. Поэтому сумму нужно преобразовать перед сложением.

## Пять примеров на чтение кода

1. **`{'A': 2, 'B': 1}`.** `get(c, 0)` берёт счётчик буквы; если буквы ещё нет, берёт ноль. Каждый проход прибавляет один.
2. **`[0, 1, 1]`.** `x` внутри функции ссылается на тот же список, что и `a`. Каждый вызов `append(1)` добавляет единицу в этот список.
3. **`2`.** `lower()` превращает `Almaty` и `ALMATY` в одинаковое `almaty`. Множество хранит только разные значения, поэтому остаются два города.
4. **`{'ab': 2, 'abc': 3}`.** `len` считает символы. Ключи словаря не повторяются: второй `ab` записывает значение в уже существующую запись.
5. **Сначала `5`, потом `None`.** `print` показывает число на экране, а `return` возвращает результат функции. У `g` нет `return`, поэтому в `x` попадает `None`.

## 1. Функции `to_num` и `clean_city`

`def` создаёт функцию. Параметр `s` — переданное ей значение, а `return` — результат, который функция отдаёт обратно.

В `to_num` последовательно убираем обычные и неразрывные пробелы, меняем запятую на точку и вызываем `float`:

```text
"1 234,50" → "1234.50" → число 1234.5
```

`\u00a0` обозначает неразрывный пробел: он выглядит почти как обычный. Пустая строка возвращает `None` — «значение отсутствует». Все суммы оплаченных заказов в твоём файле заполнены. Неправильный текст вместо числа вызовет ошибку, а не превратится в ноль.

В `clean_city` делаем три шага:

1. `strip()` убирает пробелы по краям.
2. `lower()` переводит буквы в нижний регистр.
3. Словарь `cities` находит правильное название.

Например, `" Almaty "` превращается в `"almaty"`, а затем в `"Алматы"`. В итоге разные написания объединяются в шесть городов.

## 2. Количество заказов в категориях

Основной приём почти во всех задачах — словарь-счётчик:

```python
category_counts = {}

for row in rows:
    category = row["category"]
    if category not in category_counts:
        category_counts[category] = 0
    category_counts[category] += 1
```

Сначала словарь пустой. При первой встрече категории создаём счётчик со значением ноль. Затем увеличиваем его на один. `+= 1` означает «прибавить один к текущему значению».

`sorted(category_counts, key=category_counts.get, reverse=True)` сортирует названия категорий по их счётчикам. `key=category_counts.get` указывает, какое значение сравнивать, а `reverse=True` задаёт порядок от большего к меньшему.

| Категория | Заказы |
| --- | ---: |
| Одежда | 1 529 |
| Электроника | 1 185 |
| Дом | 1 105 |
| Красота | 991 |
| Книги | 653 |

Здесь считаем все заказы, в том числе отменённые. Сумма счётчиков равна 5 463.

## 3. Выручка и средний чек

Условие `row["status"] == "оплачен"` пропускает в расчёт только оплаченные заказы. В одном словаре накапливаем суммы, в другом — количество оплаченных заказов.

```text
Средний чек = выручка / количество оплаченных заказов
```

Делить на все заказы нельзя: отменённые заказы не входят в эту выручку. В словари попадают только категории с оплаченными заказами, поэтому знаменатель положительный. В данном файле оплаченные заказы есть во всех пяти категориях.

| Категория | Выручка | Средний чек |
| --- | ---: | ---: |
| Одежда | 18 321 080 | 13 285,77 |
| Электроника | 65 270 240 | 61 286,61 |
| Дом | 10 516 320 | 10 654,83 |
| Красота | 5 507 620 | 6 188,34 |
| Книги | 2 294 100 | 3 934,99 |

В f-строке `{category:<15}` выравнивает текст влево в поле шириной 15 символов. `{revenue:>15.2f}` выравнивает число вправо и показывает два знака после точки. Это оформление вывода; само число не меняется.

## 5. Выручка по месяцам и изменение

Функция `revenue_by_month(data)` складывает суммы оплаченных заказов отдельно для каждого месяца. Она принимает список строк и возвращает словарь. В задаче 10 вызовем её снова, передав очищенный список.

В `percent_change(before, after)` используется формула:

```text
(октябрь − сентябрь) / сентябрь × 100
```

Сентябрь — база сравнения, поэтому делим на него. Отрицательное число означает снижение. Если база равна нулю, функция возвращает `None`: такой процент не определён. В нашем файле сентябрьская выручка положительная, поэтому её можно сразу вывести с `.2f`.

| --- | ---: |
| Сентябрь | 57 489 850 |
| Октябрь | 44 419 510 |

Получается **−22,74%**. Это результат до удаления дублей и TEST.

## 8. Уникальные клиенты по городам

Здесь каждому городу соответствует множество `set()`, а не число. Метод `.add()` добавляет код клиента. Если такой код уже есть, множество не меняется.

```python
if city not in customers_by_city:
    customers_by_city[city] = set()
customers_by_city[city].add(row["customer_id"])
```

`len` множества показывает количество разных клиентов:

| Астана | 981 |
| Шымкент | 655 |

| Актобе | 358 |

Учитываются все статусы и TEST. Один клиент может заказывать в разных городах, поэтому сумма этих чисел не равна общему числу уникальных клиентов.

## 9. Полные дубли

`tuple(row.values())` собирает все значения строки в кортеж. Кортеж похож на список, но его нельзя изменять. Кортеж строк можно положить во множество; словарь — нельзя. Порядок полей у строк одного `DictReader` одинаковый.

`seen` хранит уже встреченные строки. Если строка встречается впервые, добавляем её в `seen` и в список `unique_rows`. Если она уже была, увеличиваем счётчик дублей. Метод списка `.append()` добавляет элемент в конец.

Найдено **180 лишних копий, все в сентябре**. После удаления остаётся **5 283 строки**. Первую копию сохраняем: считаем именно лишние повторения. Сравниваются все поля, а не только номер заказа.

Продажи действительно снизились, но гораздо меньше, чем показывали исходные данные.

## Что важно понять

Почти всё решение состоит из трёх приёмов: **считать**, **складывать**, **сохранять уникальные значения**. Для первых двух нужен словарь с числами, для третьего — множество. Функции помогают повторно использовать одинаковое действие.

Решение упрощено под этот CSV: ожидаются известные города, заполненные суммы оплаченных заказов и положительная сентябрьская выручка. Это не универсальная обработка любых файлов. Если структура или значения поменяются, соответствующий код нужно пересмотреть.
